# Хантайшир Эко Блок — Google Sheets үнийн хүсэлтийн интеграц

Зорилтот хүснэгт:
https://docs.google.com/spreadsheets/d/1q8awc7qZYLhoPkWOfvptJAzcY25fNLUaJgFNdrJAquw/edit?gid=0

**Одоо байгаа gid=0 табыг өөрчлөхгүй.** Скрипт нь тусад нь **«Веб үнийн хүсэлт»** таб үүсгэнэ.

## Холбох алхам

1. Энэ Google Sheets файлыг **засварлах эрхтэй Google бүртгэлээр** нээнэ.
2. **Extensions → Apps Script**-ийг нээгээд GitHub дахь [Code.gs](./Code.gs) кодыг хуулж, шинэ төслийн Code.gs кодыг солиод Save дарна.
3. **setup** функцийг сонгож **Run** дарна. Google эрхийн хүсэлтийг баталгаажуулж, Sheets-д «Веб үнийн хүсэлт» таб нэмэгдсэн эсэхийг шалгана.
4. **Deploy → New deployment → Web app**, Execute as **Me**, Who has access **Anyone** гэж сонгоно. Deploy дарна.
5. Шинэ Web app URL-ийг хуулна. Хэлбэр нь: https://script.google.com/macros/s/....../exec
6. GitHub index.html дахь SITE.sheetWebhook гэсэн тохиргооны хоосон мөрөнд энэ URL-ийг оруулаад commit/merge хийнэ. URL оруулахаас өмнө автомат илгээлт идэвхжихгүй.

## Яаж ажиллах вэ?

Хэрэглэгч нэр, утас, төслийн байршил, блокийн хэмжээ, м³ оруулж зөвшөөрлийн тэмдэглэгээ хийсний дараа хүсэлт Apps Script рүү илгээгдэнэ. Скрипт «Веб үнийн хүсэлт» табд огноо, хүсэлтийн дугаар, төлөв, харилцагч, утас, байршил, төрөл, задаргаа, м³, ширхэг, нэгж үнэ, нийт үнэ, имэйл, тайлбар, UTM болон зөвшөөрлийг хадгална.

Сайт зөвхөн Google-ээс хүсэлт хадгалагдсаныг баталгаажуулсан хариу хүлээн авсан үед амжилттай гэж харуулна. Хариу ирээгүй бол давхар бүртгэл үүсгэхээс сэргийлж Sheets-ийг шалгахыг зөвлөнө.

## Туршилт (заавал)

1. Web app /exec URL-ийг нээгээд «Сервис ажиллаж байна» гэсэн мессеж харагдахыг шалгана.
2. Веб формд зохиомол тестийн мэдээлэл бөглөж илгээнэ.
3. Sheet-д шинэ мөр бүртгэгдсэнийг шалгана.
4. Сайт дээр амжилттай гэсэн хариу гарч байгааг нягтална.
5. Алдаа гарвал Apps Script → Executions хэсгийг шалгана.

## Аюулгүй байдал

- Google Sheet-ээ **нийтэд Editor эрхтэй** болгож болохгүй.
- Скрипт нь хүсэлт хадгалахын тулд эзэмшигчийн эрхээр ажиллана; Apps Script Web app нь Anyone эрхтэй тул спам эрсдэлтэй. Траффик өсөхөд CAPTCHA болон rate-limit нэмэх хэрэгтэй.
- Бодит нууц үг, токеныг GitHub-д огт оруулахгүй.
- Бодит хэрэглэгчийн мэдээллийг нээлттэй тестэд ашиглахгүй.
- Үнэ, татвар болон подоны нөхцөлийг борлуулалтын баг албан ёсоор баталгаажуулна.

**Анхаар:** Google бүртгэлийн эзэмшигч Web App-ийг deploy хийх хүртэл код бэлэн байсан ч бодит автомат бүртгэл ажиллахгүй.
